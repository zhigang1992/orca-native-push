Orca Native Push

Sends agent alerts to Orca Native through a Cloudflare relay, so the phone still gets them when the app is killed.

  1. Command Palette → Native Push: Show credentials
  2. Open the link from the desktop notification on the phone (or paste it in Orca Native Settings)
  3. Optional: Native Push: Send test alert

Debug builds use the orcanative-dev:// scheme; re-run Show credentials and change the scheme in the link, or paste server id + secret manually.
